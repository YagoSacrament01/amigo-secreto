# 🎁 Amigo Secreto

Sorteador de amigo secreto no navegador: você adiciona os nomes dos participantes e o sistema sorteia quem tira quem.

🔗 **Usar agora:** https://yagosacrament01.github.io/amigo-secreto/

## Funcionalidades
- Cadastro de participantes
- Bloqueia nomes vazios e nomes repetidos
- Exige pelo menos 4 participantes para sortear
- Sorteio justo com embaralhamento aleatório (algoritmo **Fisher-Yates**)
- Botão para reiniciar
